# Leadership 2.0 Kit

This repo holds the build kit for the Leadership 2.0 databases in Notion. Start with `Leadership2_Handoff/00_MASTER.md` and follow its build order and rules.

- The SCHEMA, MASTER and CHECK files are the source of truth for structure. Change structure here first, then in Notion.
- Once the first build is done, Notion is the source of truth for entries. Don't treat the CONTENT files as current after that.
- Build only from SCHEMA files marked approved. A SCHEMA file marked proposed needs Eduardo's yes first.
- Writing rules for anything a person reads: plain, direct language, no em dashes, never the name "Single Mingles", no personal names in entries.
